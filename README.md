💰 Loan Calculator
A Java GUI application that calculates loan repayments using both Simple and Compound interest, with a full monthly breakdown schedule.

About
Enter your loan amount, interest rate, and term — the app instantly shows your monthly payment, total repayment, and total interest for both Simple and Compound interest methods. You can switch between a full month-by-month repayment schedule for each method.

Features

GUI built with Java Swing
Simple and Compound interest calculations
Monthly repayment schedule showing payment, interest, and remaining balance
Summary totals for both interest types displayed side by side
Input validation with error messages
